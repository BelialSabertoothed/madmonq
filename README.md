## 📖 About The Project
This repository contains a custom Shopify theme implementation and a hybrid affiliate architecture proposal developed as a take-home technical assignment. The primary goal was to translate provided Figma designs into a functional, responsive Shopify storefront while addressing specific e-commerce architecture challenges.

## 🛠️ Built With
* **Shopify / Liquid** - Core templating and data rendering
* **TypeScript** - For robust and maintainable frontend logic
* **Theme App Extensions** - Extending store functionality
* *(Případně doplň další, např. Tailwind CSS, Vite, SCSS atd.)*

## ✨ Technical Highlights
* **Figma to Code:** Precise translation of provided UI mockups into responsive and reusable Shopify sections.
* **Hybrid Affiliate Architecture:** Developed a conceptual proposal and structural logic for an advanced affiliate tracking system.
* **Modern Tooling:** Utilized modern frontend workflows alongside traditional Liquid development to ensure high code quality.
